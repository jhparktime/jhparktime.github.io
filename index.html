담당한 설계

진단·검사·투약·처치를 사건(event) 단위로 구조화하고, 관련 근거를 검색한 뒤 생성하도록 파이프라인을 설계했습니다. LangChain으로 검색과 생성 단계를 연결했습니다.

검증과 결과

왜 사건 단위로 정리했는가

긴 비정형 기록에서는 진단·검사·투약·처치가 서로 다른 문장에 흩어져 있습니다. 문장 전체를 요약하는 것만으로는 기록에 필요한 사건이 빠지거나, 원문에서 확인되지 않는 설명이 들어갈 수 있습니다.

그래서 생성 전에 사건 단위로 정보를 구조화하고, 관련 근거를 검색하는 과정을 두었습니다. 어떤 정보를 근거로 기록을 생성하는지 되짚을 수 있게 하는 것이 설계의 기준이었습니다.

직접 맡은 작업

진단·검사·투약·처치의 사건 정의와 입력 구조를 정리하고, LangChain으로 검색과 생성 단계를 연결했습니다. 생성 결과에 필요한 정보가 남아 있는지와 원문의 근거가 반영됐는지를 평가하며 사건 정의와 검색 범위를 보완했습니다.

결과와 적용 범위

의무기록 생성 데이터톤 본선에 진출했습니다. 산출물은 검색·생성·평가 과정을 연결한 프로토타입입니다. 검증의 대상은 생성 기록의 정보 누락과 원문 근거 반영 여부였습니다.

이 프로젝트에서 배운 것은 모델 선택만큼 생성 전의 입력 구조와 생성 후의 검증 기준이 중요하다는 점입니다.

폐혈관 연구의 문제 재정의와 평가 조건

점수와 실제 목적이 달랐던 지점

CT 영상에서 혈관을 분할하는 모델을 개선해도 가느다란 혈관이 중간에서 끊기는 문제가 남았습니다. 겹치는 영역의 정확도와 혈관의 연결성을 함께 확인할 필요가 있었습니다.

해결할 문제를 혈관 영역의 분할에서 끊어진 연결의 복원까지 넓혔습니다. CNN 분할 결과를 중심선과 노드·간선으로 표현하고, GraphSAGE 기반 링크 예측으로 연결 후보를 평가했습니다.

검증과 비교

250개 CT 볼륨을 환자 단위로 학습 150, 검증 50, 테스트 50으로 나누었습니다. Dice와 clDice를 함께 보고, 말단점·단절 구간·연결 요소도 확인했습니다.

논문 Table 1에서 CNN 대비 CNN+GNN의 Dice는 65.3%에서 67.1%, clDice는 54.2%에서 61.7%로 개선됐습니다. 두 지표의 증가는 각각 1.8%p와 7.5%p이며, 평가 조건은 원문에서 확인할 수 있습니다.

성과와 남은 한계

연구를 제1저자 논문으로 한국컴퓨터그래픽스학회 논문지에 게재했고, SOFTCON 연구부문 우수상을 받았습니다. 복원 이후에도 말단점과 연결 요소에서 정답 구조와 차이가 남아 있어, 연결성 지표와 실제 영상을 함께 확인했습니다.

AI와 계산 도구의 역할을 나눈 이유

학습 데이터를 고른 기준

Qwen2.5-3B-Instruct가 생성한 추론 중 최종 정수 답변이 학습 문제의 정답과 일치하는 결과를 선택했습니다. 어려운 학습 문제에서는 힌트를 바탕으로 Qwen이 추론을 다시 쓰게 하고, 검증을 통과한 결과를 LoRA 학습 자료로 사용했습니다.

출력 길이와 합의 수준

16개 답변을 샘플링해 정규화한 정수 답변의 투표로 결과를 고릅니다. 출력 한도에 걸린 샘플만 길이를 늘리며, 합의 수준이 개선되는 조건을 만족할 때 답을 교체합니다. 긴 답변이라는 이유만으로 우선하지 않는 구조입니다.

기존 투표의 우세가 약한 경우에는 Python 풀이 실행을 보조 경로로 사용합니다. 실행 결과의 합의를 확인하고, 실행 시간·메모리·허용 라이브러리를 제한합니다.

실행을 되짚을 수 있게 만든 부분

모델과 설정을 고정하고 입력·출력 해시를 기록했습니다. 중단 후 재개, 정수 답변 추출과 제출 파일 검증을 포함해 학습·추론·제출의 실행 조건을 문서에 남겼습니다.

모델 카드에 기록한 결과

동결한 R3 SC16·길이 확장·PAL 구성의 공개 리더보드 참고 점수는 0.79783입니다. 기록된 평가 범위의 참고값이며, 최종 추론에 점수를 입력하지 않습니다. 모델 카드에서 설정과 학습 데이터 계보를 확인할 수 있습니다.
